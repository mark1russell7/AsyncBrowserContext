## Mutants

A mutant is a copy of the runtime with a known error. A good test suite fails with each mutant.

The chart gives the part of the old tests that passed with each mutant of the old runtime. With the old tests, the runtime without async support (m4) passed 82 of 217 tests. The runtime with one global value (m5) passed 148 of 217 tests. Thus, the old tests could not find these errors.

The table under the chart gives the last run of Stryker on the current tests. Stryker makes a mutant from each small part of the source code and starts the tests for each mutant. The score is the part of the mutants that the tests find.
