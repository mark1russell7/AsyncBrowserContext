## The interactive pages

Each page of this section starts real code with the library in your browser. The build of this site uses the Vite plugin of the library, so the code of the scenarios gets the same transform as your code.

| Page | What it shows |
| --- | --- |
| [Context timeline](/explore/timeline) | Each read of a variable in six scenarios, with the library and with two global variables. |
| [Frame tree](/explore/frames) | The frames that `run()` makes, step by step, from the real store of the runtime. |
| [Transform viewer](/explore/transform) | The input and the output of the Babel preset. |
| [Event rule](/explore/events) | Rule C13 with your own clicks. |
| [Diagrams](/explore/diagrams) | The parts of the runtime and the transform pipeline. |
